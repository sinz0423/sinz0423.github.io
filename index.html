全国大学生电子设计竞赛 — 简易自行瞄准装置

挑战

四天三夜极限完成一套自动循迹小车 + 二维云台瞄准系统。小车沿黑色轨迹逆时针行驶，车载 405nm 蓝紫激光笔需在行进中自动瞄准并命中 A4 幅面紫外感光靶，光斑直径 ≤ 0.5cm。发挥部分要求光斑沿靶面圆弧同步画圆，同步误差 ≤ 1/4 圈。

方案

K230 嵌入式平台（RISC-V + KPU NPU）部署轻量化 YOLO 检测 + 传统颜色分割 / 霍夫圆检测混合方案。球坐标空间解算 + 变比例串级 PID 控制（偏差大时 P 大，偏差小时 P 小），三颗异构 MCU（视觉处理器 → 逻辑主控 → 运动控制器）串口通讯。

30ms检测-解算-通讯全流程

全国大学生智能汽车竞赛 — 双车跟随组

挑战

双车禁止无线 / 超声波通讯。后车摄像头须置于车尾，距前轮 > 15cm，镜头中心高度 ≤ 10cm，不得俯视赛道——从根本上剥夺了直接观察赛道的能力，完全依赖前车 LED 灯光信号进行视觉追踪。赛道包含环岛等复杂元素，过弯时灯光目标运动模式剧烈变化。

方案

前车：图像预处理 → 逆透视变换 → 滑动窗口赛道边界搜索 → 灯光编码发送（曼彻斯特编码）。后车：FFT 频域提取灯光调制频率 → 动态 ROI + 卡尔曼滤波预测 → 抗环境光干扰（遮光罩 + 曝光控制 + 时序滤波）。自主设计驱动板。

6ms捕获+处理+识别每帧
2.5 m/s双车协同速度
1kHz灯光调制频率

燃煤锅炉温度场数字孪生模型

挑战

锅炉炉膛内部温度极高，测温点仅能布置在炉壁有限位置。核心问题：利用稀疏传感器数据反演炉膛截面连续温度场分布。CFD 数值模拟单次计算约 12 小时，需降阶模型实现秒级重建；锅炉变工况运行时温度场非线性变化剧烈，传统线性 POD 方法捕捉能力有限。

方案

提出高维流场压缩至独立单标量潜空间、解码器共享高维输入的改进方法，融合 POD（物理可解释性）与 CAE（非线性表达能力）优势。采用 LSSVM 完成边界条件到潜变量的回归预测——相比普通神经网络，LSSVM 在小样本条件下泛化能力更好。

0.9680速度场 R²

Vision

研究方向

研究生阶段希望扎根于视觉感知、智能控制与具身智能的交叉领域。具身智能的核心挑战——智能体在开放环境中实时感知、理解物理世界并做出可靠决策——与我在竞赛中面对的运动平台视觉伺服问题本质一致：摄像头捕捉的是智能体与环境持续交互中的动态视觉流，感知结果直接影响控制指令，控制执行反过来改变下一帧观测。这种感知-行动闭环恰好落在控制工程的学科脉络中。

◉
视觉语言模型在机器人操作场景中的泛化能力
◉
基于视觉反馈的精细操控策略
◉
仿真到现实的迁移（Sim-to-Real）
◉
将物理机理约束嵌入学习模型的 PINN 方向

不满足于在仿真环境中刷榜调参，希望技术落地到真实物理系统——让机器人在嘈杂工厂可靠抓取，在陌生家庭环境安全导航。
这需要深厚的控制理论基础、扎实的视觉算法功底，以及对物理世界的敬畏。
